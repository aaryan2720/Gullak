# 🚀 Gullak - Quick Start Guide

## ⚡ Get Started in 3 Steps

### Step 1: Install Dependencies
```bash
npm install
```

### Step 2: Start Development Server
```bash
npm start
```

### Step 3: Run the App
- Press `i` for iOS
- Press `a` for Android
- Press `w` for Web

---

## 📱 What You'll See

### 5 Complete Screens Ready to Explore:

1. **🏠 Home** - Portfolio dashboard with quick actions
2. **💰 Invest** - Round-up settings and investment tracking
3. **🎯 Goals** - Financial goals with progress tracking
4. **📚 Learn** - Gamified finance education
