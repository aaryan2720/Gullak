## **Appendix: Tech Details**

### **AI Agent Details**

#### **Auto Round-up Agent**
- **ML Model**: Spending pattern prediction (Random Forest)
- **Triggers**: Real-time transaction webhook
- **Learning**: Adapts round-up amounts based on cashflow
- **Autonomy Level**: 95% (user sets initial rules only)

#### **Goal Intelligence Agent**
- **ML Model**: Goal recommendation (Collaborative Filtering)
- **Triggers**: New user onboarding, monthly check-ins
- **Learning**: Analyzes similar user journeys
- **Autonomy Level**: 80% (user approves goals)

#### **Learning Coach Agent**
- **ML Model**: Adaptive learning path (Reinforcement Learning)
- **Triggers**: Quiz completion, engagement metrics
- **Learning**: Adjusts difficulty based on performance
- **Autonomy Level**: 90% (self-paced curriculum)

#### **Investment Advisor Agent**
- **ML Model**: GPT-4 fine-tuned on financial data
- **Triggers**: User questions, market events
- **Learning**: Remembers user preferences over time
- **Autonomy Level**: 70% (provides advice, user executes)

#### **Portfolio Manager Agent**
- **ML Model**: Mean-variance optimization (Markowitz)
- **Triggers**: Daily market data, quarterly rebalancing
- **Learning**: Adapts to user's actual risk tolerance
- **Autonomy Level**: 95% (auto-executes rebalancing)

#### **Fraud Guard Agent**
- **ML Model**: Anomaly detection (Isolation Forest)
- **Triggers**: Every transaction
- **Learning**: Continuous learning from transaction history
- **Autonomy Level**: 100% (blocks suspicious transactions instantly)
